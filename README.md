## 6. On-Page SEO Technical Standards & SOP

### Title Tag Standard:
- Length: 50–60 characters (pixel width < 580px).
- Formula: `[Primary Keyword] | [Brand Name / Geographic Hook]`
- Example: `Lawn Care Horn Lake MS | Brown Lawn Care & Cleaning Service`

### Meta Description Standard:
- Length: 140–160 characters.
- Formula: `[Action Hook] + [Core Service] in [Location] by [Brand]. [Trust Signals: Licensed, Insured, 15+ Yrs Exp]. [CTA + Phone].`
- Example: `Professional lawn care, mowing & cleaning in Horn Lake, MS & 50-mile radius. Licensed, insured & bonded. Call (662) 571-1048 for free quotes!`

### Heading Structure:
- Exactly **one `<h1>`** per page strictly aligned with the primary page keyword.
- Logical `<h2>` subsections with semantic `<h3>` sub-features.
- Headings never used as empty visual style tags.

## 9. Technical SEO Specifications

- **Robots.txt:** Located at `/robots.txt`. Allows standard Googlebot/Bingbot crawling of public routes, blocks private `/dashboard/` and `/api/` endpoints, references `https://www.brownlawncarecleaningservicellc.com/sitemap.xml`.
- **Dynamic XML Sitemap:** Located at `/sitemap.xml`. Generated via TanStack Start server handler with correct `<loc>`, `<lastmod>`, `<changefreq>`, and `<priority>`.
- **Self-Referential Canonical Tags:** Included on every single route to prevent duplicate content variations across trailing slashes, www/non-www, and parameters.
- **Custom 404 Response:** Located in root route with helpful navigation back to Home, Services, Service Areas, and a clickable phone button.

## 10. Core Web Vitals & Image Optimization Standards

- **Largest Contentful Paint (LCP):** Preload hero image/video, optimize font loading via `preconnect` for Google Fonts (`Inter`), inline critical CSS variables.
- **Cumulative Layout Shift (CLS):** Explicit `aspect-ratio` and width/height dimensions set on all images, icons, and hero containers.
- **Interaction to Next Paint (INP):** Lightweight React state management, lazy-loading for offscreen carousels and maps.
- **Image Attributes:** Every `<img>` tag includes descriptive, keyword-rich `alt` text and `loading="lazy"` (except above-the-fold hero elements).
